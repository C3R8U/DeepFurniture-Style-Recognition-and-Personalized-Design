# 文件字段说明

## source_instances.csv

- `sample_id`: 由官方场景编号、实例索引、身份编号组合计算得到的稳定校验ID（不是官方原始身份编号）。
- `scene_id`, `instance_index`, `instance_number`: 真实场景及实例定位。
- `identity_id`: 官方标注 `identityID`，用于产品级分组，不能用随机值替代。
- `raw_category_id`, `raw_category`, `raw_style_ids`, `raw_styles`: 官方原始标签。
- `candidate_category`, `candidate_style`, `mapping_issue`: 候选目标标签与待确认原因，均非经过人工批准的标签。
- `scene_image`, `scene_annotation`: 相对官方解压目录的原始路径。
- `x_min`, `y_min`, `x_max`, `y_max`: 对应家具在场景中的标注边界框。

## annotation_review.csv

`reviewer1_*` 与 `reviewer2_*` 为两名独立标注者的类别和风格结果。`adjudicated_*` 为最终复核标注；`decision` 仅使用 `approved`、`rejected`、`pending`；`decision_reason` 写明图像被剔除的原因。两个标注者的原始决策不能在复核后覆盖，否则科恩卡帕系数将失真。

## near_duplicate_pairs_review.csv

包含两张真实图片的 `sample_id`、`identity_id`、pHash汉明距离及“待审核”的决策提示。`hamming<=8` 为候选近重复，不自动等同于相同产品。完成复核后修改核验表的 `decision`，然后重新运行近重复检测。

## master_index.csv / train.csv / validation.csv / test.csv

只允许由 `03_build_splits.py` 写出。记录真实的 `sample_id`、官方 `identity_id`、训练划分、风格类别、家具类别、来源相对路径、实例裁剪框、原始标签和人工复核状态。所有该类文件要求严格配额，不能生成假编号以凑足记录。

## preprocessing_provenance.csv

记录各图片的分割掩码来源与处理状态。`instance_segmentation` 为官方实例分割；`bbox_fallback_DEBUG_ONLY` 仅用于软件调试，不能混作论文真实分割结果。

## validation_report.json / annotation_agreement.json

分别存放配额、产品身份跨划分、跨划分近重复的审核结果，以及两位标注员独立标签的κ值。报告由程序计算，不手工填写或复制论文预期统计值。
