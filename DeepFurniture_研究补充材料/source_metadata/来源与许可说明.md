# 原始资料来源与再分发边界

官方数据集主页：https://huggingface.co/datasets/byliu/DeepFurniture

官方标签源文件：

- https://huggingface.co/datasets/byliu/DeepFurniture/blob/main/data/metadata/styles.json
- https://huggingface.co/datasets/byliu/DeepFurniture/blob/main/data/metadata/categories.json
- https://huggingface.co/datasets/byliu/DeepFurniture/blob/main/data/metadata/dataset_info.json

本目录JSON依据上述可公开查看的小型文件逐项核对，未将原始标签擅自修改为论文中的五类别版本。

数据集页面显示许可为 `afl-3.0`，原元信息JSON内部的 `license` 字段仍写有 `Add license here`。正式复制或公开原始图像时须依照原发布方许可条款判断是否允许再分发。本包不含原图像或已下载的43.5GB源数据。

数据集介绍所称约24,000场景/170,000实例/20,000独立身份是大约规模；`dataset_info.json`原文精确提供 `num_scenes=24182`、`num_furnitures=24742`、`num_queries=7264`。它们是不同统计口径，不应混为“12500张实验图”。
